## STRAPI-EMAIL-FIELD

A Strapi v5 custom field plugin that integrates the [Unlayer](https://unlayer.com/) drag-and-drop email template editor via `react-email-editor`. The field type is `"json"` on the server side and stores `{ design, html }` — the Unlayer design JSON and the rendered HTML output.

## Commands

```bash
yarn build          # Compile plugin for distribution (admin + server)
yarn watch          # Watch mode for development
yarn watch:link     # Watch mode + symlink for local Strapi integration
yarn verify         # Verify plugin structure via @strapi/sdk-plugin
```

There are no lint or test scripts configured.

## Architecture

The plugin follows Strapi's standard plugin structure with two independent halves:

**`/admin/src/`** — Admin panel UI (React, runs in browser)

- `index.ts` — Registers the custom field with Strapi's admin app; the `Input` component is lazy-loaded
- `components/Input/index.tsx` — The core React component; mounts `react-email-editor`, listens for `design:updated` events, and writes `{ design, html }` back via Strapi's field `onChange`

**`/server/src/`** — Server-side plugin logic (Node.js)

- `register.ts` — Registers the custom field with type `"json"` and sets the input UI size (12 cols, non-resizable)
- `index.ts` — Re-exports the register function

**`/dist/`** — Compiled output; generated by `yarn build`. Both ESM (`.mjs`) and CJS (`.js`) variants are emitted per the `exports` map in `package.json`.

## Key Implementation Details

- **Editor ref management:** `emailEditorRef` holds the `EmailEditor` component ref; `unlayerRef` holds the Unlayer editor instance obtained in `onReady`. An `isInternalChange` ref prevents re-initialising the design when a `design:updated` event triggers `onChange`, which would cause a re-render loop.
- **External value changes** (e.g. locale switches): handled in a `useEffect` watching `value` — if the new value's `design` differs from what's loaded, `loadDesign` is called on the Unlayer instance.
- **Styled wrapper:** The `<Wrapper>` styled component forces the inner `<iframe>` to `width: 100%`. The editor container has a minimum height of 800px.
- **Plugin ID:** `"strapi-email-field"` (defined in `admin/src/pluginId.ts` and mirrored in `package.json`).
